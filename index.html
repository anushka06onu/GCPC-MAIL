How to Send Your HTML Email
1

Method A: Sending directly via Gmail (The Copy-Paste Trick)

1. Click the "Copy Email HTML" button in this dashboard to copy the fully compiled HTML code.
2. Open Gmail in Google Chrome, click "Compose", and type a placeholder word in the email body (e.g. [RENDER]).
3. Right-click the placeholder word, click "Inspect" to open Chrome Developer Tools.
4. In the inspect pane, right-click the selected HTML element, click "Edit as HTML".
5. Replace the placeholder element completely by pasting the copied HTML, then close the inspect pane.
6. Your gorgeous, customized GCPC email is now rendered beautifully inside Gmail and ready to send!

2

Method B: Sending via Automated Scripts (Node.js / Python)

If your club uses automation scripts to mail students:
1. Click "Download HTML" to download the template file (e.g., email_template.html).
2. Load this file in your script (e.g., using Python's open('email_template.html', 'r').read() or Node.js fs.readFileSync()).
3. Send it as an HTML-type email using libraries like Nodemailer in Node.js, or smtplib / email.mime in Python.

3

Method C: Using Email Platforms (Mailchimp, SendGrid, etc.)

If sending via mass-mailing services:
1. Open your mailing platform and create a new Campaign.
2. Select "Upload HTML" or "Code Your Own" / "HTML Code Editor".
3. Paste the copied source code into the editor. These platforms will automatically host the images and track clicks for you!

Why are absolute image links important?

Email clients (like Outlook or Gmail app) are isolated environments. They cannot load local files like assets/gcpc-logo.png. In order for recipients to see the logos, every image URL must be a public web address. We have automatically preconfigured these logos to pull from your public GitHub repository production branch (githubusercontent.com) so that your emails will load with 100% correct graphics immediately!
